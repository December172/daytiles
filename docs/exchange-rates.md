# 开箱即用的官方汇率换算

[简体中文（默认）](exchange-rates.md) | [English](exchange-rates.en.md)

记账页面和支出编辑器提供「汇率换算」，支持 CNY、HKD、TWD、USD。打开换算器后会自动从公开官方来源获取数据，无需注册、API 密钥或配置。已有 24 小时内下载的缓存时直接复用；也可点击「刷新汇率」主动更新。

下载后的汇率表可供所有相关币种组合离线换算。界面分别显示官方数据日期、本机下载时间和来源链接。支出编辑器中的「使用换算金额」仅填入当前金额，仍需保存支出；目标币种固定为该笔支出的账本币种。

没有接入需要用户自备密钥的商业数据服务，也没有内置共享密钥、自建代理或账号系统。官方数据的使用仍受来源网站条款约束；HKMA 的[使用条款](https://www.hkma.gov.hk/eng/other-information/terms-and-conditions.shtml)包含非商业用途及来源标注要求。本应用在汇率页面明确标注来源并提供原始网站入口，不表示获得官方背书。

## 换算与缓存

- CFETS 读取 `USD/CNY`、`HKD/CNY`，按「每单位外币对应多少人民币」解释；CNY 的基准值为 1。忽略其他币种的不同报价单位，避免把网页每 100 单位报价直接当作 JSON 单位。
- HKMA 的 `usd`、`cny`、`twd` 是「每单位外币对应多少港币」，HKD 的基准值为 1。选择返回记录中日期最新且所需字段完整、有效的同一行。
- 换算公式为「原币种基准值 ÷ 目标币种基准值」。同一次换算始终使用同一官方来源、同一观察日期，不混合两张表。界面显示的是本机计算的参考换算率。
- 使用 `BigDecimal`，交叉汇率保留 12 位小数，最终金额四舍五入至最小货币单位。拒绝无效、非正、异常精度和超出范围的数据。
- 两个来源的完整快照单独保存于 SharedPreferences；可离线推导反向及其他币种对。缓存同时存在时选择观察日期较新的可用快照，同日优先 CFETS。
- 自动加载仅在缓存缺失或下载满 24 小时后联网；手动刷新绕过此时限。若 CFETS 请求失败，自动尝试 HKMA；断网或解析失败时保留最后一次成功快照，并显示失败提示。
- 请求 URL 为固定官方地址，不包含用户选择的金额、支出、日记、备注或预算。没有后台轮询。HTTPS 请求不跟随重定向，设置超时和 128 KiB 响应上限。
- 没有修改 Room schema 或已有记录、预算及币种统计。「清除已保存汇率」单独删除汇率缓存。

官方参考数据可能因周末、假期、月报发布或端点暂时不可用而过时。用于个人记账估算，不代表银行或银行卡实际结算价，也不包含手续费；使用前应核对界面的数据日期。
