# DayTiles 0.2.0

[简体中文（默认）](0.2.0.md) | [English](0.2.0.en.md) | [繁體中文（香港）](0.2.0.zh_HK.md) | [繁體中文（台灣）](0.2.0.zh_TW.md)

这一里程碑围绕充分利用屏幕高度的月历、紧凑导航和快速任务输入重新设计规划界面，同时保留已有离线数据。

## 改动

- 提供日程、视图、目标、小组件和我的五个主标签，使用共用工具栏与重新设计的侧边栏。
- 月历以周日为首日，显示相邻月份日期，支持滑动切换、年月选择、离线农历标签，以及任务、日记和贴纸预览。
- 扁平任务列表采用圆形完成控件，底部快速输入面板支持标题、详情、标签、优先级和可选提醒。
- 保留完整任务编辑与子任务；工具栏适配键盘，并修正侧边栏返回行为。
- 提供用于每日/每周完成目标的周日期栏和编辑器、小组件目录，以及分组的本地规划工具。
- 更新浅色/深色外观、简体中文界面，并在 README 中展示不含个人内容的截图。

Room 数据库结构未改变。日记、任务和贴纸仍采用独立的本地数据模型，无需账户或后端服务。

## 验证

- 离线 `assembleDebug`、`testDebugUnitTest` 和 `lintDebug` 通过：10 项单元测试通过，Lint 无错误，存在 50 条警告。
- 设备检查覆盖任务创建、完成、编辑、子任务、删除、导航、月份选择、侧边栏返回、浅色/深色外观及简体中文。
- 数据库比对确认，设备检查后每张原有表均保留原始记录；临时测试数据已经清理。

## 下载与限制

- `DayTiles-0.2.0-debug.apk` 是可安装的 debug 签名测试构建，沿用 0.1.0 的分发方式，并非面向 Play Store 上架的正式产物。
- `SHA256SUMS` 包含 APK 校验值。
- 小组件添加依赖桌面启动器；测试设备上未确认成功放置到桌面。
- 农历标签不包含节气和法定节假日标注。
- 改版遵循参考应用的主要外观，并非逐像素复刻其所有页面或主题。
