# DayTiles 0.3.0

[简体中文（默认）](0.3.0.md) | [English](0.3.0.en.md) | [繁體中文（香港）](0.3.0.zh_HK.md) | [繁體中文（台灣）](0.3.0.zh_TW.md)

本次發佈新增全部日程、任務回收站和每日/月度記賬預算，並包含課程表、農曆設定及繁體中文支持等改進。日記、任務、貼紙和賬目均保存在本地，無需賬戶或後端服務。

## 新增與改進

- **全部日程**：在按日期分組的時間線上查看跨月份任務，支持完成狀態篩選、勾選、編輯和快速新增。
- **回收站**：刪除任務時保留詳情、原日期、完成狀態和子任務，支持還原、永久刪除和清空；永久刪除需要確認。
- **記賬與預算**：記錄每日支出、分類和備註，查看每日/月度彙總，設定獨立預算並顯示剩餘額度或超支。CNY、HKD、TWD 和 USD 分別記賬，金額使用整數最小貨幣單位保存。
- **課程表與設定**：整合課程查看和編輯，支持重疊課程；增加農曆顯示開關，並改進小工具新增提示和導覽。
- **語言與文檔**：補充香港及台灣繁體中文界面，提供簡體中文、香港繁體中文和台灣繁體中文 README 及模擬器截圖。
- **數據升級**：數據庫升級至 schema 9，保留原有日記、任務、子任務、貼紙、目標和課程記錄。

## 驗證

- 0.3.0 構建的 `assembleDebug`、`assembleDebugAndroidTest` 和 `lintDebug` 通過。
- Android API 37 模擬器上的全部 **32 項測試通過**，無失敗、錯誤或跳過項；覆蓋金額計算、數據庫遷移、持久化、本地化及日程、回收站、記賬預算界面流程。
- 同一功能代碼此前已在 vivo V2425A（Android 16 / API 36）的獨立測試副本上通過 **32 項測試**；原應用覆蓋升級後，7 張原有數據表、設定和導入貼紙校驗一致。
- Lint 無錯誤，保留 2 條構建工具版本更新提示。詳細記錄見[功能與驗證文檔](https://github.com/December172/daytiles/blob/main/docs/planner-finance.md)。

## 下載與安裝

- 支持 Android 8.0（API 26）及以上版本。
- `DayTiles-0.3.0-debug.apk` 是可直接安裝的 debug 簽名構建，沿用 0.2.0 的簽名，支持覆蓋升級；版本號為 **0.3.0**，versionCode 為 **4**。
- `SHA256SUMS` 提供 APK 的 SHA256 校驗值。
- 桌面小工具新增仍依賴啟動器支持；本次未在 vivo 上測試新增小工具。
