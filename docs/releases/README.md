## 维护方式

- 无语言后缀的版本文件是默认简体中文说明；`.en.md`、`.zh_HK.md` 和 `.zh_TW.md` 分别对应英文、香港繁体和台湾繁体。
- 新增版本或修订说明时同步维护四种语言，并更新上表。
- GitHub Release 正文先展示完整简体中文说明，再以三个可展开章节提供其他语言的完整内容；源文档的语言链接指向本目录对应文件。
- 历史版本的测试数量、警告、功能限制及发布附件名称按原记录保留。
