# DayTiles 0.1.0

[简体中文（默认）](0.1.0.md) | [English](0.1.0.en.md) | [繁體中文（香港）](0.1.0.zh_HK.md) | [繁體中文（台灣）](0.1.0.zh_TW.md)

Initial feature release with an offline-first calendar, journal, tasks, stickers, focus clock, widgets, weekly course timetable, and a separate Course Scheduler. The README includes screenshots captured from the Android app with status and navigation bars cropped out.

The attached `app-debug.apk` is a debug-signed build for testing; it is not a Play Store-ready release artifact.
