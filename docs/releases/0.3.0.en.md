# DayTiles 0.3.0

[简体中文（默认）](0.3.0.md) | [English](0.3.0.en.md) | [繁體中文（香港）](0.3.0.zh_HK.md) | [繁體中文（台灣）](0.3.0.zh_TW.md)

This release adds Full schedule, a task Recycle Bin, and daily/monthly expense budgets, alongside course timetable improvements, lunar settings, and Traditional Chinese support. Journals, tasks, stickers, and expenses stay on the device without an account or backend.

## Additions and improvements

- **Full schedule**: view tasks across all months on a date-grouped timeline, with completion filters, checkboxes, editing, and quick creation.
- **Recycle Bin**: retain deleted tasks' details, original dates, completion state, and subtasks. Restore, permanently remove, or empty the bin; permanent removal requires confirmation.
- **Expenses & budgets**: record daily costs, categories, and notes; review daily/monthly totals and independent budgets with remaining or over-budget amounts. CNY, HKD, TWD, and USD use separate ledgers and exact integer minor units.
- **Timetable and settings**: combine course viewing and editing, support overlapping classes, add a lunar-date switch, and improve widget-placement feedback and navigation.
- **Languages and documentation**: add Hong Kong and Taiwan Traditional Chinese interfaces, plus Simplified Chinese, Hong Kong Traditional Chinese, and Taiwan Traditional Chinese READMEs and emulator screenshots.
- **Data upgrade**: migrate to schema 9 while preserving existing journals, tasks, subtasks, stickers, targets, and courses.

## Validation

- The 0.3.0 `assembleDebug`, `assembleDebugAndroidTest`, and `lintDebug` builds passed.
- All **32 tests passed** on the Android API 37 emulator, with no failures, errors, or skipped cases. Coverage includes money handling, migration, persistence, localization, and schedule, recycle-bin, expense, and budget UI flows.
- The same feature code previously passed **32 tests** in an isolated copy on a vivo V2425A (Android 16 / API 36). An in-place update of the original app preserved all seven original entity tables, settings, and imported stickers.
- Lint reported zero errors and two tool-version update advisories. See the [feature and verification report](https://github.com/December172/daytiles/blob/v0.3.0/docs/planner-finance.md).

## Download and installation

- Requires Android 8.0 (API 26) or later.
- `DayTiles-0.3.0-debug.apk` is an installable debug-signed build using the same certificate as 0.2.0 for in-place updates. The version is **0.3.0**, with versionCode **4**.
- `SHA256SUMS` contains the APK's SHA256 checksum.
- Widget pinning still depends on launcher support; widget placement was not tested on vivo in this verification.
