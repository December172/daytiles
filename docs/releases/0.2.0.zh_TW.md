# DayTiles 0.2.0

[简体中文（默认）](0.2.0.md) | [English](0.2.0.en.md) | [繁體中文（香港）](0.2.0.zh_HK.md) | [繁體中文（台灣）](0.2.0.zh_TW.md)

這一里程碑圍繞充分利用螢幕高度的月曆、緊湊導覽和快速任務輸入重新設計規劃介面，同時保留已有離線資料。

## 改動

- 提供日程、檢視、目標、小工具和我的五個主標籤，使用共用工具欄與重新設計的側邊欄。
- 月曆以週日為首日，顯示相鄰月份日期，支援滑動切換、年月選擇、離線農曆標籤，以及任務、日記和貼紙預覽。
- 扁平任務列表採用圓形完成控制元件，底部快速輸入面板支援標題、詳細資料、標籤、優先順序和可選提醒。
- 保留完整任務編輯與子任務；工具欄適配鍵盤，並修正側邊欄返回行為。
- 提供用於每日/每週完成目標的週日期欄和編輯器、小工具目錄，以及分組的本機規劃工具。
- 更新淺色/深色外觀、簡體中文介面，並在 README 中展示不含個人內容的截圖。

Room 資料庫結構未改變。日記、任務和貼紙仍採用獨立的本機資料模型，無需帳戶或後端服務。

## 驗證

- 離線 `assembleDebug`、`testDebugUnitTest` 和 `lintDebug` 通過：10 項單元測試通過，Lint 無錯誤，存在 50 條警告。
- 裝置檢查覆蓋任務建立、完成、編輯、子任務、刪除、導覽、月份選擇、側邊欄返回、淺色/深色外觀及簡體中文。
- 資料庫比對確認，裝置檢查後每張原有表均保留原始記錄；臨時測試資料已經清理。

## 下載與限制

- `DayTiles-0.2.0-debug.apk` 是可安裝的 debug 簽章測試建置，沿用 0.1.0 的分發方式，並非面向 Play Store 上架的正式產物。
- `SHA256SUMS` 包含 APK 校驗值。
- 小工具新增依賴啟動器；測試裝置上未確認成功放置到桌面。
- 農曆標籤不包含節氣和法定節假日標註。
- 改版遵循參考應用的主要外觀，並非逐畫素復刻其所有頁面或主題。
