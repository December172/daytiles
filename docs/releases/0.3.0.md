# DayTiles 0.3.0

本次发布新增全部日程、任务回收站和每日/月度记账预算，并包含课程表、农历设置及繁体中文支持等改进。日记、任务、贴纸和账目均保存在本地，无需账户或后端服务。

## 新增与改进

- **全部日程**：在按日期分组的时间线上查看跨月份任务，支持完成状态筛选、勾选、编辑和快速添加。
- **回收站**：删除任务时保留详情、原日期、完成状态和子任务，支持恢复、永久删除和清空；永久删除需要确认。
- **记账与预算**：记录每日支出、分类和备注，查看每日/月度汇总，设置独立预算并显示剩余额度或超支。CNY、HKD、TWD 和 USD 分别记账，金额使用整数最小货币单位保存。
- **课程表与设置**：整合课程查看和编辑，支持重叠课程；增加农历显示开关，并改进小组件添加反馈和导航。
- **语言与文档**：补充香港及台湾繁体中文界面，提供简体中文、香港繁体中文和台湾繁体中文 README 及模拟器截图。
- **数据升级**：数据库升级至 schema 9，保留原有日记、任务、子任务、贴纸、目标和课程记录。

## 下载与安装

- 支持 Android 8.0（API 26）及以上版本。
- `DayTiles-0.3.0-debug.apk` 是可直接安装的 debug 签名构建，沿用 0.2.0 的签名，支持覆盖升级；版本号为 **0.3.0**，versionCode 为 **4**。
- `SHA256SUMS` 提供 APK 的 SHA256 校验值。
- 桌面小组件添加仍依赖启动器支持；本次未在 vivo 上测试添加小组件。
