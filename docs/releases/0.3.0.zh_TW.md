# DayTiles 0.3.0

[简体中文（默认）](0.3.0.md) | [English](0.3.0.en.md) | [繁體中文（香港）](0.3.0.zh_HK.md) | [繁體中文（台灣）](0.3.0.zh_TW.md)

本次釋出新增全部日程、任務回收筒和每日/月度記帳預算，並包含課表、農曆設定及繁體中文支援等改進。日記、任務、貼紙和帳目均儲存在本機，無需帳戶或後端服務。

## 新增與改進

- **全部日程**：在按日期分組的時間軸上檢視跨月份任務，支援完成狀態篩選、勾選、編輯和快速新增。
- **回收筒**：刪除任務時保留詳細資料、原日期、完成狀態和子任務，支援還原、永久刪除和清空；永久刪除需要確認。
- **記帳與預算**：記錄每日支出、分類和備註，檢視每日/月度彙總，設定獨立預算並顯示剩餘額度或超支。CNY、HKD、TWD 和 USD 分別記帳，金額使用整數最小貨幣單位儲存。
- **課表與設定**：整合課程檢視和編輯，支援重疊課程；增加農曆顯示開關，並改進小工具新增回饋和導覽。
- **語言與文件**：補充香港及臺灣繁體中文介面，提供簡體中文、香港繁體中文和臺灣繁體中文 README 及模擬器截圖。
- **資料升級**：資料庫升級至 schema 9，保留原有日記、任務、子任務、貼紙、目標和課程記錄。

## 驗證

- 0.3.0 建置的 `assembleDebug`、`assembleDebugAndroidTest` 和 `lintDebug` 通過。
- Android API 37 模擬器上的全部 **32 項測試通過**，無失敗、錯誤或跳過項；涵蓋金額計算、資料庫遷移、持久化、在地化及日程、回收筒、記帳預算介面流程。
- 同一功能程式碼先前已在 vivo V2425A（Android 16 / API 36）的獨立測試副本上通過 **32 項測試**；原應用覆蓋更新後，7 張原有資料表、設定和匯入貼紙校驗一致。
- Lint 無錯誤，保留 2 條建置工具版本更新提示。詳細記錄見[功能與驗證文件](https://github.com/December172/daytiles/blob/main/docs/planner-finance.md)。

## 下載與安裝

- 支援 Android 8.0（API 26）及以上版本。
- `DayTiles-0.3.0-debug.apk` 是可直接安裝的 debug 簽章建置，沿用 0.2.0 的簽章，支援覆蓋更新；版本號碼為 **0.3.0**，versionCode 為 **4**。
- `SHA256SUMS` 提供 APK 的 SHA256 校驗值。
- 主畫面小工具新增仍依賴啟動器支援；本次未在 vivo 上測試新增小工具。
